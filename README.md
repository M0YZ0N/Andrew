1. Краткое описание проекта
     1.1. Мартынов Андрей Михайлович
     1.2. Группа: ЛПЦ22-ОБ-БИ1
     1.3. Тема проекта: Прогнозирование цены на автомобиль по его характеристикам с помощью полносвязной нейронной сети
     1.4. Цель проекта: Разработка системы интеллектуальной оценки стоимости автомобилей на основе их технических характеристик, включающей как классификацию по ценовым категориям, так и точный регрессионный прогноз рыночной цены с использованием глубоких нейронных сетей.
     1.5. Задачи проекта:
  Собрать или сгенерировать данные об автомобилях с основными параметрами и ценой.
  Провести предобработку данных: очистка, удаление дубликатов и аномалий, приведение признаков к числовому виду.
  Выполнить визуальный анализ данных и корреляционный анализ признаков с ценой.
  Преобразовать цену в три ценовых класса (бюджетный, средний, премиум) для задачи классификации.
  Построить и обучить полносвязную нейронную сеть для классификации уровней цены и регрессии для предсказания цены.
  Оценить качество моделей на тестовой выборке и интерпретировать результаты.

    1.6. Анотация: В проекте рассматривается задача прогнозирования цены автомобиля на основе его характеристик. В качестве исходных данных используются параметры автомобилей (мощность, пробег, год выпуска, объем двигателя, тип коробки передач, тип топлива, тип кузова) и их цена. После предобработки данных выполняется деление цен на три класса по квантилям распределения. На основе подготовленных признаков строится полносвязная нейронная сеть, обучаемая в режиме многоклассовой классификации. Дополнительно строится регрессионная модель для предсказания конкретной цены. В результате получается модель, способная по параметрам автомобиля оценить его ценовой уровень и предсказать стоимость.
